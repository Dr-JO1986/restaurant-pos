คู่มือนี้เหมาะกับใคร

ทำตามบทบาทของคุณเพื่อจัดการร้าน รับออร์เดอร์ และส่งงานให้ครัวได้ต่อเนื่อง ก่อนเริ่มใช้งาน ให้ตรวจสอบว่าอุปกรณ์เชื่อมต่ออินเทอร์เน็ต และได้รับลิงก์ระบบกับบัญชีจากผู้ดูแลร้านแล้ว

1 เจ้าของร้านจัดการร้าน เมนู บัญชี และออร์เดอร์ 2 พนักงานรับออร์เดอร์บันทึกออร์เดอร์โต๊ะและส่งเข้าครัว 3 พ่อครัว / KDSติดตามและอัปเดตสถานะอาหาร
หมายเหตุ: ชื่อเมนู ปุ่ม หรือลิงก์ที่ปรากฏอาจต่างกันเล็กน้อยตามการตั้งค่าร้าน หากเข้าใช้งานไม่ได้หรือไม่พบเมนูที่ต้องการ ให้ติดต่อเจ้าของร้านหรือผู้ดูแลระบบ
1

Owner / Merchant

สำหรับเจ้าของร้าน

จัดเตรียมข้อมูลร้านและบัญชีทีมงาน แล้วติดตามงานประจำวันจากแดชบอร์ด

1.1 เข้าสู่ระบบและจัดการภาพรวมร้าน

  1. เปิดลิงก์ระบบของร้านในเว็บเบราว์เซอร์ แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของร้าน
  2. เปิดหน้า แดชบอร์ด เพื่อดูภาพรวมร้าน รายการเมนู และทางลัดไปยังการจัดการออร์เดอร์ บัญชีพนักงาน และการเรียกพนักงาน
  3. ตรวจสอบข้อมูลร้านและการตั้งค่าที่แสดงในหน้าแดชบอร์ดให้ถูกต้อง เช่น ชื่อร้าน รายละเอียด และข้อมูลติดต่อหรือการชำระเงินที่ระบบร้องขอ
  4. บันทึกทุกครั้งหลังแก้ไข และตรวจดูข้อความยืนยันหรือข้อผิดพลาดบนหน้าจอ
ก่อนเปิดรับออร์เดอร์ออนไลน์

หากแดชบอร์ดแจ้งให้กรอกข้อมูลร้านหรือข้อมูลบัญชีให้ครบ ให้ดำเนินการให้เรียบร้อยก่อน ลูกค้าจึงจะสามารถส่งออร์เดอร์ออนไลน์ได้ตามปกติ

1.2 จัดหมวดหมู่และเมนูอาหาร

  1. จากแดชบอร์ด เปิดส่วนจัดการเมนู แล้วเพิ่มหมวดหมู่ เช่น อาหารจานหลัก เครื่องดื่ม หรือของหวาน
  2. เพิ่มเมนูในหมวดที่ต้องการ กรอกชื่อ ราคา และรายละเอียดตามช่องที่ระบบแสดง รวมถึงรูปภาพหรือข้อมูลตัวเลือกเพิ่มเติมถ้ามี
  3. ตรวจสอบการตั้งค่าสถานะเปิดขาย/ปิดขายและข้อมูลที่กรอก แล้วบันทึกเมนู
  4. ทบทวนรายการเมนูทั้งหมดบนแดชบอร์ด หากราคา ชื่อ หรือรายละเอียดเปลี่ยน ให้แก้ไขและบันทึกก่อนเริ่มรับออร์เดอร์

เมนูที่ยังไม่เปิดขายหรือไม่มีเมนูที่เปิดขาย อาจไม่ปรากฏให้พนักงานเลือกในหน้าคีย์ออร์เดอร์

1.3 สร้างและดูแลบัญชีพนักงาน / พ่อครัว

  1. เปิดหน้า จัดการบัญชีพนักงาน จากแดชบอร์ด
  2. กรอกชื่อผู้ใช้และรหัสผ่านตามแบบฟอร์ม จากนั้นเลือกบทบาทให้ตรงกับหน้าที่ของผู้ใช้งาน
  3. กด สร้างบัญชี และแจ้งข้อมูลเข้าสู่ระบบแก่พนักงานเป็นการส่วนตัว
  4. ตรวจสอบรายชื่อ สถานะ และบทบาทในรายการพนักงาน หากลืมรหัสผ่านให้ใช้เมนูตั้งรหัสผ่านใหม่ หรือปิดใช้งานบัญชีเมื่อไม่ต้องการให้เข้าใช้
บัญชี / บทบาทการใช้งานโดยทั่วไป
พนักงานรับออร์เดอร์ใช้หน้าคีย์ออร์เดอร์เพื่อบันทึกออร์เดอร์หน้าร้านและส่งรายการเข้าครัว
พ่อครัว / ครัวเข้าใช้หน้าจอ KDS เพื่อดูรายการอาหารและอัปเดตสถานะการทำอาหาร

กำหนดรหัสผ่านที่คาดเดายาก ไม่ใช้รหัสผ่านร่วมกัน และเปลี่ยนรหัสผ่านทันทีหากสงสัยว่ามีผู้อื่นทราบ

1.4 ติดตามออร์เดอร์และพิมพ์ใบเสร็จ

  1. เปิดหน้า จัดการออร์เดอร์และโต๊ะ เพื่อค้นหาและตรวจสอบออร์เดอร์ของร้าน รวมถึงออร์เดอร์ออนไลน์ที่ยืนยันการชำระเงินแล้ว
  2. เลือกดูรายละเอียดหรือรายการโต๊ะที่ต้องการ ตรวจสอบเลขออร์เดอร์ รายการอาหาร ยอดรวม และสถานะก่อนดำเนินการต่อ
  3. กด ดู / พิมพ์ใบเสร็จ ในออร์เดอร์ที่ต้องการ ระบบจะแสดงหน้าสรุปบิล
  4. กดปุ่มพิมพ์ใบเสร็จบนหน้าสรุป หรือใช้ Ctrl + P แล้วเลือกเครื่องพิมพ์และกระดาษให้เหมาะสม
ตรวจสอบก่อนพิมพ์

ตรวจเลขออร์เดอร์และยอดเงินให้ตรงกับบิลที่ต้องการพิมพ์ ในหน้าต่างพิมพ์ของเบราว์เซอร์ให้เลือกเครื่องพิมพ์ที่ถูกต้อง และตรวจตัวอย่างก่อนสั่งพิมพ์

1.5 รับแจ้งเตือนเมื่อลูกค้าเรียกพนักงาน

  1. เปิดหน้าแดชบอร์ดหรือส่วน ลูกค้าเรียกพนักงาน ค้างไว้บนอุปกรณ์ที่พนักงานตรวจดูได้
  2. รายการที่รอจะระบุหมายเลขโต๊ะและเวลาที่เรียก โดยหน้าจอจะตรวจสอบรายการใหม่อัตโนมัติเป็นระยะ
  3. ส่งพนักงานไปยังโต๊ะที่แสดง แล้วกด รับทราบ เพื่อปิดรายการเรียกที่จัดการแล้ว
  4. ตรวจดูรายการที่ยังค้างอยู่เป็นระยะ เพื่อไม่ให้มีสายเรียกตกหล่น
ข้อควรทราบ: การกดรับทราบเป็นการจัดการรายการแจ้งเตือน ไม่ใช่การยืนยันว่าออร์เดอร์หรือการชำระเงินเสร็จสมบูรณ์
2

Staff / POS

สำหรับพนักงานรับออร์เดอร์

บันทึกรายการให้ถูกโต๊ะ ตรวจสอบก่อนส่ง และยืนยันว่าออร์เดอร์เข้าครัวแล้ว

2.1 เข้าสู่ระบบ POS

  1. เปิดลิงก์ระบบที่เจ้าของร้านแจ้งให้ แล้วไปยังหน้าเข้าสู่ระบบ
  2. กรอกชื่อผู้ใช้และรหัสผ่านที่ได้รับ ตรวจสอบว่าใช้บัญชีพนักงานรับออร์เดอร์
  3. เข้าสู่หน้าคีย์ออร์เดอร์ของร้าน หากเข้าสู่ระบบไม่ได้ ให้ตรวจการพิมพ์ชื่อผู้ใช้/รหัสผ่าน หรือติดต่อเจ้าของร้านเพื่อรีเซ็ตรหัสผ่าน

2.2 รับออร์เดอร์ลูกค้าที่โต๊ะ

  1. ถามและยืนยันหมายเลขโต๊ะกับลูกค้าก่อนเริ่มบันทึกรายการ หากเป็นออร์เดอร์กลับบ้าน ให้เลือกประเภทออร์เดอร์กลับบ้านแทน
  2. เลือกเมนูและจำนวนตามที่ลูกค้าสั่ง ระบุตัวเลือกหรือหมายเหตุเพิ่มเติมในช่องที่ระบบมีให้
  3. ทวนรายการ จำนวน และโต๊ะกับลูกค้า ตรวจยอดรวมก่อนส่ง
  4. กด ส่งออร์เดอร์เข้าครัว หน้าจอจะแสดงข้อความยืนยันเมื่อส่งสำเร็จ พร้อมเลขออร์เดอร์
  5. หากยังไม่เห็นข้อความยืนยัน ให้ตรวจรายการก่อนส่งซ้ำ เพื่อป้องกันออร์เดอร์ซ้ำ และแจ้งเจ้าของร้านหากพบปัญหา
เคล็ดลับ:
  • เลือกโต๊ะให้ตรงกับลูกค้าทุกครั้ง
  • อย่ากดส่งซ้ำเมื่อระบบกำลังประมวลผล
  • แจ้งเลขออร์เดอร์ให้ทีมครัวหรือผู้เกี่ยวข้องเมื่อจำเป็น

2.3 เช็กลิสต์ก่อนส่งออร์เดอร์

  • ประเภทออร์เดอร์ถูกต้อง: รับประทานที่ร้านหรือกลับบ้าน
  • หมายเลขโต๊ะตรงกับโต๊ะของลูกค้า (กรณีรับประทานที่ร้าน)
  • รายการอาหาร จำนวน และตัวเลือกตรงตามที่ลูกค้าสั่ง
  • ตรวจยอดรวมและหมายเหตุ ก่อนกดส่งเข้าครัว
  • ได้รับข้อความยืนยันการส่งและเลขออร์เดอร์
3

Kitchen Display System · KDS

สำหรับพ่อครัว / หน้าจอห้องครัว

ติดตามออร์เดอร์ที่เข้ามาแบบอัตโนมัติ และอัปเดตสถานะให้ทีมหน้าร้านทราบ

3.1 ล็อกอินเข้าหน้าจอ KDS

  1. เปิดลิงก์ระบบที่เจ้าของร้านแจ้ง แล้วเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านสำหรับพ่อครัว/ครัว
  2. ตรวจชื่อร้านที่แสดงบนหน้า Kitchen Display System ให้แน่ใจว่าเป็นร้านที่ถูกต้อง
  3. เปิดหน้านี้ค้างไว้บนจอครัว หากต้องการให้เห็นชัดขึ้น สามารถกด เต็มหน้าจอ
  4. หากต้องการเสียงเตือนเมื่อมีออร์เดอร์ใหม่ ให้กด เปิดเสียงแจ้งเตือน และอนุญาตเสียงจากเบราว์เซอร์หากมีข้อความถาม

3.2 ดูรายการอาหารแบบ Real-time

  • ออร์เดอร์ใหม่จะแสดงบนหน้าจอโดยอัตโนมัติ ไม่จำเป็นต้องรีเฟรชหน้าเอง
  • ตรวจเลขออร์เดอร์ หมายเลขโต๊ะหรือประเภทออร์เดอร์ และรายการอาหารพร้อมจำนวน/หมายเหตุ
  • สังเกตสถานะการเชื่อมต่อบนแถบด้านบน หากขึ้นแจ้งว่าเชื่อมต่อขัดข้อง ให้ตรวจอินเทอร์เน็ตและรอระบบลองเชื่อมต่อใหม่
  • เมื่อไม่มีออร์เดอร์ค้าง หน้าจอจะแสดงข้อความว่าไม่มีออร์เดอร์ค้าง ออร์เดอร์ใหม่จะแสดงเมื่อเข้ามา

3.3 เปลี่ยนสถานะอาหาร

  1. เมื่อเริ่มลงมือทำ ให้เปิดออร์เดอร์และกดปุ่มสถานะ กำลังทำ สำหรับรายการหรือออร์เดอร์ที่ระบบให้จัดการ
  2. ทำอาหารตามรายการและหมายเหตุที่แสดง ตรวจความครบถ้วนก่อนส่งออกจากครัว
  3. เมื่ออาหารในออร์เดอร์พร้อมแล้ว กด เสร็จแล้ว เพื่อแจ้งทีมหน้าร้านว่าพร้อมเสิร์ฟ
  4. ตรวจรายการที่ยังค้างบนหน้าจอต่อไป และดำเนินการกับออร์เดอร์ใหม่ตามลำดับงานของร้าน
สถานะบนหน้าจอควรกดเมื่อความหมายต่อทีม
กำลังทำครัวเริ่มเตรียมอาหารแล้วทีมทราบว่าออร์เดอร์อยู่ระหว่างทำ
เสร็จแล้วอาหารพร้อมส่งให้ลูกค้าหรือทีมเสิร์ฟออร์เดอร์พร้อมเสิร์ฟ

3.4 ปิดงานอย่างถูกต้อง

  • กดเปลี่ยนสถานะตามงานจริง ไม่กดเสร็จก่อนอาหารพร้อม
  • แจ้งหน้าร้านเมื่อพบรายการไม่ชัดเจนหรือมีข้อจำกัดด้านวัตถุดิบ
  • ก่อนออกจากอุปกรณ์ ให้กด ออกจากระบบครัว เพื่อป้องกันผู้อื่นเข้าใช้งานบัญชี
